MAHAPRABHU STORES - NPM VERSION

1. Install Node.js LTS from https://nodejs.org/
2. Extract this folder.
3. Open the folder, click address bar, type cmd, press Enter.
4. Run: npm install
5. Run: npm run dev
6. Open Chrome: http://localhost:3000
7. Admin: http://localhost:3000/admin.html

Admin can edit MRP, selling price, and stock; manage order status.
Data is stored locally in the data folder. This is a starter local server, not yet a production cloud deployment.
